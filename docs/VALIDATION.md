# v0.1.0-rc.1 验收记录

状态：**已完成下列发布候选的本机验证，尚未达到完整首版交付条件。** 独立干净 Windows 与更广泛兼容性验收仍待完成。记录日期：2026-10-16。

**最新 UI 结果：** 52 项增强回归在实际 DPR 1.0 / 1.5 下全部通过，截图归属警告为零。`Qt::MSWindowsOwnDC` 修复已由真实归档模型的桌面合成画面确认；最大化、还原、拆出、拖回四个阶段均比较有效模型前景与帧缓冲，避免两张空白图误判。150% 下的原生客户区、渲染缓冲和截图尺寸一致；自绘按钮、标题双击以及最大化→最小化→正常窗口均恢复原矩形。早期读回成功但上屏失败、锁屏阻断、高 DPI 取整和窗口恢复失败记录保留，不计为通过。

原始日志、归档测试路径和截图保存在本机 `logs/`、`.local/` 等忽略目录，不随公开仓库或发行包发布。本文仅保留不含个人路径和真实素材的汇总。

## 构建与运行环境

本机 Windows x64 Release 已编译桌面程序、库服务、Filament 渲染助手、SAI1 助手和 Qt 媒体助手，支持中文工作区路径。主要组件为 Qt 6.8.3、Filament 1.78.0、Assimp 5.4.3、SQLite 3.50.4、Zstandard 1.5.7；3D 验证使用 RTX 4070 Ti / OpenGL。

便携目录内的 Python 3.11.9、Node 24.19.0 与依赖可脱离开发用 PATH 启动。QtTest 日志中的 Windows 版本字符串不能替代独立 Windows 10 兼容性验收。

## 性能记录

### 服务查询

数据来自 `logs/core-scale.json`。使用合成的一万/十万条元数据、真实命名管道、JSON 和每次最多 200 条返回记录；资产复用一个已存在的小 PNG 路径。每场景执行 31 次，表中热缓存 P95 排除首次。此测量不包含实际缩略图解码、压缩或 UI 绘制。

| 记录数 | 场景 | 首次调用 ms | 热缓存中位数 ms | 热缓存 P95 ms |
|---:|---|---:|---:|---:|
| 10,000 | 首页 | 16.320 | 14.397 | 16.893 |
| 10,000 | 标签并集＋类型 | 22.997 | 22.429 | 23.200 |
| 10,000 | 名称子串 | 17.461 | 15.224 | 18.063 |
| 100,000 | 首页 | 20.908 | 19.182 | 23.095 |
| 100,000 | 标签并集＋类型 | 118.443 | 119.776 | 131.530 |
| 100,000 | 名称子串 | 26.050 | 24.115 | 28.237 |

一万记录的已测查询满足 P95 ≤100 ms 目标。十万记录标签并集 P95 **131.530 ms**，不能宣称十万记录所有筛选均低于 100 ms。“首次调用”没有清空操作系统文件缓存，不能标作严格冷缓存结果。真实多文件、冷缓存和后台导入压力的组合测试仍待补充。

### 无边框四主题 UI 基线

以下来自 `logs/ui-perf-*-warm.json`，为 UI UX 字号和布局整理前的四主题基线。窗口为 1920×1080，网格视口 1365×808；合成元数据复用已复制的真实缓存缩略图，每场景 600 次脚本滚动。首屏包含 IPC 首页和 28 张缩略图读入 QPixmap。不同记录有独立资产 ID；本测量不代表一万张不同原文件同时解码。

| 主题 | 记录数 | 热缓存首屏 ms | QWidget 绘制 CPU P95 ms | 绘制事件间隔 P95 ms |
|---|---:|---:|---:|---:|
| 暖白 | 10,000 | 130.615 | 5.242 | 16.698 |
| 石墨黑 | 10,000 | 110.345 | 5.555 | 16.626 |
| 深海蓝 | 10,000 | 118.575 | 5.914 | 16.761 |
| 冰青 | 10,000 | 136.888 | 5.786 | 16.814 |
| 石墨黑 | 100,000 | 112.702 | 5.498 | 16.656 |

已测热缓存首屏均低于 300 ms。绘制 CPU 与绘制事件间隔均不是 GPU present 时间，也不能直接当作端到端显示帧率；完整连续滚动帧耗时 P95 ≤20 ms 目标仍需独立呈现时间测量。

首次按需生成与后台工作场景（`logs/ui-performance-final.json`）：

| 场景 | 首屏 28 张卡片 ms | 绘制 CPU P95 ms | 绘制事件间隔 P95 ms |
|---|---:|---:|---:|
| 10,000 条、无派生缩略图缓存 | 7689.953 | 5.060 | 16.904 |
| 10,000 条、同时导入 2500 张图 | 126.225 | 4.679 | 16.730 |

无派生缓存包含实际首次生成，操作系统文件缓存未清空，不能称为严格磁盘冷缓存；该场景首屏约 7.69 秒，不满足热缓存 300 ms 指标，列表绘制仍在后台生成期间继续。后台导入场景有 43 次约 0.1 秒采样确认任务处于 running，并在场景结束前完成，确实与浏览重叠。

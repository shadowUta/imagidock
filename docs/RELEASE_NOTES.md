# v0.1.0-rc.1 · 首版发布候选

本版本是创想坞的首个 Windows x64 发布候选。素材库、预览、关联、备份、恢复、多窗口和 MCP 已具备可运行实现。**完整首版尚未交付**；独立干净 Windows 和更广泛源文件组合仍需验收，具体通过记录和未覆盖范围见 [VALIDATION.md](https://github.com/shadowUta/imagidock/blob/v0.1.0-rc.1/docs/VALIDATION.md)。

最新 UI 保留四色晕染玻璃和整体圆角，使用自绘标题栏。原生模型显示、高 DPI 渲染区域及最大化后最小化的窗口恢复已修复；两档缩放各通过 52 项 UI 回归，四个窗口阶段均核对真实桌面模型前景。

## 本候选包含

- 原生 C++20 / Qt 6 桌面界面，左侧目录/类型、虚拟化卡片网格、右侧检查器及详情；名称、标签、类型、目录和状态组合筛选。
- 普通图片完整显示、缩放与平移；PSD/PSB 保存合成图、SAI 内嵌预览、SAI2 实验合成解码及明确低清降级；Blender/Aseprite 可配置后台预览。
- Filament 实时 GLB/glTF、OBJ/FBX 适配、动画、视角快照、法线方向、多槽材质覆盖；PSD/PSB/SAI/SAI2 可作为绑定贴图。
- 多预览与封面、库内可索引预览和外部派生图、关联跳转和返回栈、不可删除的固定材质角色及可排序自定义关联标签。
- 虚拟目录、批量导入、内容去重压缩备份、模型依赖恢复、批量/目录取用、库包导入导出、回收站、占位和错误中心。
- 独立页签、可拆合窗口、同库数据同步、后台任务进度/取消/重试和中断记录恢复。
- 36 个官方 TypeScript SDK MCP 工具和项目本地 imagidock-assets Skill；四主题参数、角色排序、revision 冲突保护与长任务 job_id。
- 便携运行依赖、逐文件 SHA-256 清单、第三方原始声明和独立完整对应源码包。

## 视觉与渲染修正

四种主题的界面名称为 **暖白 · Warm Ivory、石墨黑 · Graphite、深海蓝 · Ocean、冰青 · Mint**，保留柔和晕染和半透明玻璃面板。透明贴图直接叠在预览背景上，不加棋盘格。

模型上下倒置已经真实 Filament 红上蓝下测试验证修正。四个真实归档 GLB 的 12 次并发重复快照均成功，同模型重复输出哈希一致且画面正立。最新最大化、还原、页签拆出和拖回均通过真实桌面画面与帧缓冲的前景对照。四主题网格、透明图、模型与设置共 7 张实际合成截图已检查。标题栏、窗口按钮与页签按钮使用同主题自绘样式，保留拖动、缩放、最大化和最小化。

## 当前验证摘要

已有格式测试 10/10、源格式材质测试 3/3、Filament 渲染测试 4/4、MCP SDK 测试 2/2、真实服务 MCP 12 项断言通过。核心 QtTest 有 10 个通过结果，包含 32 项并发取用互不覆盖与仅改贴图触发父备份过期回归；最新 UI 在实际 100% / 150% 缩放下各有 52 项断言通过。

便携包在同机清除开发 PATH、Qt/Python/Node 环境变量后通过 52 项 UI 断言，包内 Python/Node 可启动；格式助手冷启动不会向程序目录写入字节码缓存。包内 PSD/PSB/SAI/SAI2/WAV/MP4 六项实际解码与 17 项 MCP 服务断言通过。ZIP 清单、哈希及换目录运行重复核对；这些结果均不能替代独立干净 Windows 验收。

一万记录服务查询的已测热缓存 P95 为 16.893–23.200 ms；最终 1080p 石墨黑网格首屏 28 张缓存缩略图为 119.380 ms，界面绘制 CPU P95 为 5.438 ms。十万记录标签并集 P95 为 131.530 ms。UI 测试复用真实缓存缩略图和合成元数据，绘制 CPU 不是 GPU 呈现时间；不宣称所有查询或目标机器均达标。

## 已知边界

- 目标平台为 Windows 10/11 x64，但独立 Windows 10 和未安装开发环境的干净系统验证尚未完成；本机没有可用的 WindowsSandbox.exe。
- SAI1 依赖内嵌低清预览；SAI2 解码为实验兼容，广泛真实版本尚未覆盖。PSD/PSB 不重绘图层，也不编辑源文件；缺少保存合成画面时可能需要补充预览。
- FBX 已做原创样例渲染/依赖恢复，尚未覆盖各种 DCC 导出器、复杂材质和动画组合。音视频支持取决于实际编码，不能仅凭扩展名保证可播放。
- 外部预览和源格式绑定派生图最长边为 2048；解码任务有输入大小、像素、内存与时间限制，原件备份不因此缩小。
- 库包导入为独立库，不合并现有库；占位只恢复库记录，不创建磁盘文件；仅索引资产若未补齐备份，不会自动包含原文件。
- 严格冷缓存、真实不同文件的大库与后台导入组合压力、不同 GPU/驱动及更广泛超长路径需要后续验收。

# 创想坞使用说明

## 开始整理

运行 ImagiDock.exe。工具栏可添加文件或递归扫描文件夹，也可直接拖入文件。导入默认只记录位置，勾选备份后会在后台压缩保存文件。目录栏是素材库自己的虚拟目录，移动和重命名资产不改动外部原件。

名称、目录、类型、标签、备份／缺失／收藏可组合筛选。同一组多选取并集，不同组之间取交集。网格只按需加载可见卡片。

## 浏览与关系

单击卡片更新右侧检查器，双击进入详情。图片滚轮缩放、拖动平移；模型左键旋转、右键平移、滚轮缩放，可复位、播放动画和保存视角快照。音视频使用播放条定位、调音量和循环。

详情的“管理关联”和“管理预览”开关开启后可以添加、删除和拖动排序。普通模式点击关联卡片进入目标资产；点击库内预览可跳转到对应资产，外部导入预览不建立可索引资产。返回按钮或 Esc 沿关联历史返回，主页清空历史。弹窗打开时 Esc 优先关闭弹窗。

材质角色与普通标签分开。固有色、法线、粗糙度、金属度、AO、自发光、透明度、ORM 是固定角色，角色本身不能删除，绑定可以修改。一个角色在同一槽只能有一个有效绑定，槽位从 1 开始，可以输入 4 及更大的槽位。法线支持 OpenGL / DirectX，ORM 解释为 R=AO、G=粗糙度、B=金属度。自定义角色可选对应渲染角色；模型更新后的材质名变化会报错，避免自动套入错误槽。

PSD/PSB 只读取保存的合成画面；无合成画面时可从原软件重新保存或添加高清预览。SAI1 显示内嵌预览；SAI2 优先完整合成，实验解码不兼容时显示低清预览。界面显示实际预览尺寸和种类。Blender / Aseprite 需在设置中配置本机工具路径。

## 备份与修复

备份压缩原文件以及模型必要依赖，普通设计参考关系不会无限递归备份。源文件更新会标记备份过期；更新成功前保留旧备份。取用时可按单项、多项或虚拟目录导出，目标冲突会改名保留双方。

删除移入库内回收站，外部文件保留。关联目标删除后显示缺失。错误中心可重新链接、路径替换、重试、恢复与建立占位；占位仅恢复数据库记录，不创建磁盘空文件。恢复或重链接沿用资产 ID。

导出库包包含一致的数据库快照、已有备份和用户预览。未备份的索引文件不会自动装入包，可选择先补齐备份。导入库包建立独立库，首版不合并到现有库。

## 页签、窗口与任务

页签可以新建、复制、关闭、拖出成独立窗口或拖回。各页签有各自筛选和返回栈，多窗口共享库服务与后台任务。任务入口可查看进度、取消、失败原因和重试。关闭最后窗口有任务时可留在托盘；明确退出停止未完成任务，重启后从任务列表重试。

## 文件位置与自动化

默认库在程序旁 `data/library`。库目录包含 `library.sqlite3`、压缩对象、预览、缓存和任务记录。请使用库导出功能获得运行时一致的副本。MCP 通过同一服务访问库，不直接改数据库，工具和 Skill 说明见 mcp/README.md。

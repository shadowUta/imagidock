# 创想坞使用说明

本文对应 **v0.1.0-rc.1 发布候选**。当前能力与尚未完成的验收分别见 [发布说明](RELEASE_NOTES.md) 和 [验收记录](VALIDATION.md)。

## 启动与素材库

解压便携包到可写目录，运行 `ImagiDock.exe`。默认在程序旁的 `data/library` 建库。“文件 → 打开 / 新建素材库”可选择其他独立库，也可使用命令行 `ImagiDock.exe --library <目录>`。首次启动不需要配置 Python、Node 或 Qt 开发环境。

库目录包含数据库、压缩对象、用户预览图和可再生缓存，任务记录随库持久保存。需要迁移运行中的库时使用“导出当前素材库”，获得一致的数据库快照和所选备份数据。

## 导入、目录与筛选

使用“添加文件”“添加文件夹”或拖入文件。文件夹会递归扫描并映射为库内目录。导入窗口默认只索引来源，勾选“同时创建压缩备份”才会后台复制和压缩；失败项不阻止其他素材继续导入，详情见任务结果。

目录栏属于素材库自己的虚拟结构。库内改名、移动不移动外部原件。相同来源再次导入会更新已有记录；相同内容位于不同来源时可以保留独立资产。右侧信息栏可修改名称、标签、收藏和库内目录。

本地 v4 右栏顶部可用左右箭头、圆点或左右方向键切换主文件和已添加的预览图。粗体资产名支持双击或 F2 重命名，右侧星形图标切换收藏。文件大小在名称下方靠左，格式靠右；来源与备份分别显示绿勾或红叉。标签各自显示在小框中，末尾圆形“＋”添加标签，右键或 Delete 可移除标签。名称和标签操作直接保存，不再需要单独点击保存按钮。

名称、目录、类型、标签及状态可组合筛选。**同一维度取并集，不同维度取交集**：选择“角色、贴图”标签会显示拥有其中任意标签的素材，再加“图片”类型则只保留图片。状态包含收藏、已备份、来源丢失、备份过期和回收站；排序可选名称、最近修改、最近导入。

## 卡片与详情预览

单击卡片查看右侧信息，双击打开详情。卡片按需读取缩略图；图片等比完整显示，音频显示波形，视频显示首个可解码帧，模型显示固定视角快照。

| 素材 | 预览与操作 | 范围与限制 |
|---|---|---|
| 普通图片 | PNG、JPEG、WebP、BMP、GIF、TIFF、TGA；滚轮缩放、拖动平移、适应窗口、100% | 透明区域透出当前背景，不显示棋盘格；超大图受解码上限约束 |
| Photoshop | PSD、PSB 保存的合成画面，保留透明度并处理 ICC | 不编辑或重新合成图层；无可用合成图时尝试内嵌预览，否则提示补充预览 |
| PaintTool SAI | `.sai` 内嵌预览；`.sai2` 优先保存的完整合成图 | SAI1 通常低清；SAI2 为实验兼容解码，版本不兼容时尝试低清预览，显示实际尺寸和种类 |
| 模型 | GLB/glTF、OBJ＋MTL、FBX；旋转、平移、缩放、复位、可解析动画和快照 | glTF 为主路径，OBJ/FBX 转换适配；复杂 FBX 和广泛导出器差异尚未完整验收 |
| 音频 | WAV、MP3、FLAC、OGG、M4A；播放、暂停、定位、音量、循环 | 实际可用性取决于文件编码；波形采样有时间上限 |
| 视频 | MP4、WebM、MOV、MKV；首帧、播放与定位 | 扩展名不保证内部编码可解码，失败原因会显示 |
| 创作源文件 | Blender、Aseprite/ASE 后台生成预览 | 在设置中指定本机程序；未配置时仍可索引、备份和关联 |

模型用左键拖动旋转、中键拖动平移、滚轮缩放。工具栏可复位、播放动画和“保存模型快照”；快照加入当前资产的预览列表。主文件按钮返回素材本身。模型显示上下方向已用真实渲染测试修正。

PSD/SAI 缺少高清画面时，可在原软件保存兼容合成画面，或给该资产关联高清 PNG/PSD。界面里的低清预览不代表原文件分辨率下降，备份仍保存原文件。

## 关联、预览列表和材质

进入详情后打开“管理关联 / 材质”或“管理预览”。管理界面可以添加、移除、拖动排序，也提供上移/下移操作。普通模式单击关联卡片进入目标资产。预览列表单击切换画面；双击库内预览或使用“打开所选预览资产”跳转到对应资产。

库内预览保存资产索引，目标缺失时可修复。外部预览只保存最长边不超过 2048 像素的压缩派生图并保留透明度，不创建独立可索引资产。可指定某张预览为封面，或恢复模型/主文件的默认缩略图。

返回按钮、Esc 或 Alt+左沿关联历史返回；“素材库”按钮返回主页并清空当前页签的详情历史。弹窗存在时 Esc 先关闭弹窗。

材质角色与普通标签分开：固有色、法线、粗糙度、金属度、AO、自发光、透明度、ORM 是固定角色，其名称和顺序不可修改，绑定可以增删。自定义关联标签可以添加、删除、排序，必要时显式映射到渲染角色。“资产 → 管理关联标签”管理这些自定义项。

槽位从 1 开始；默认三个槽位并非上限，可添加第 4 个或更多槽位。`固有色`/`固有色_1` 指第一槽，后缀 2、3 对应后续槽，以编辑器中的实际槽号和材质名为准。同槽同角色只有一个有效绑定。模型更新导致槽位或材质名不匹配时会报告问题，避免错误套用。

法线支持 OpenGL/DirectX 方向；ORM 为 R=AO、G=粗糙度、B=金属度。PSD、PSB、SAI、SAI2 也可作为绑定贴图，预览会先生成最长边 2048 的 PNG 派生图；低清降级会报告，坏图或丢失贴图不会被无提示忽略。所有材质调整仅保存为库内预览配置，不改写模型或贴图原件。

## 备份、取用与修复

选择一个或多个资产后可“备份所选”，也可右键关闭备份标记；关闭标记保留已有有效备份。模型备份包含必要依赖，例如 glTF BIN/贴图、OBJ MTL/贴图和明确绑定的材质贴图；普通参考关系不会递归复制整条关联链。备份按内容去重，验证成功后才标记就绪。源文件变化显示“备份过期”，更新成功前保留旧版本。

有效来源可以“在文件夹中显示”或“用默认程序打开”；来源失效时按钮置灰。有有效备份时仍可预览和取用。使用“取用 / 下载文件”导出原文件及依赖；多选批量取用，或在目录栏右键取用整个虚拟目录。目标已有同名文件时改名保留双方。

删除只移入库内回收站，外部原文件保留。引用方显示丢失及原名称/路径。错误中心汇总来源或依赖缺失、预览解码失败、材质槽不匹配、过期或损坏备份，支持重新链接、批量路径替换、重试和恢复。**建立占位只恢复原 ID 的库内记录，不创建磁盘空文件。** 恢复记录或重新链接后，关联沿用原 ID。

“导出当前素材库”生成 `.imagidock` 包，包含一致的数据库快照、已有备份与用户预览。仅索引文件不自动进入包；选择“导出前补齐所有备份”才会尝试补齐。导入库包建立新的独立库，当前版本不合并到已有库。

## 页签、窗口、主题与任务

页签可以新建、复制、关闭，拖出页签栏成为独立窗口，再拖回同一素材库的其他窗口。不同库的页签保留在各自窗口。各页签独立保存筛选与返回栈，多窗口共享同库数据和后台任务。

“窗口 → 设置”提供四种主题：**暖白 · Warm Ivory、石墨黑 · Graphite、深海蓝 · Ocean、冰青 · Mint**。同时可调卡片大小、内存缓存、任务并发、默认备份及 Blender/Aseprite 路径。四套配色保留玻璃面板与柔和晕染；主窗口及设置、任务、关联管理等弹窗使用整体圆角、自绘标题栏。拖动标题区移动窗口，双击主窗口标题区最大化或还原，边缘可缩放；系统文件选择器保持系统样式。

后台任务显示进度、取消、失败原因和重试。取消批量任务保留已完成项。关闭最后窗口时，若仍有任务且系统托盘可用，会留在托盘继续；通过“退出”明确停止未完成任务。重启后中断任务可从任务列表重试。

| 快捷键 | 操作 |
|---|---|
| Ctrl+O | 添加素材文件 |
| Ctrl+T / Ctrl+Shift+T | 新建 / 复制当前页签 |
| Ctrl+N / Ctrl+W | 新建窗口 / 关闭页签 |
| Esc / Alt+左 | 返回上一层，Esc 优先关闭弹窗 |
| Ctrl+J / Ctrl+E | 后台任务 / 错误中心 |
| Ctrl+, | 设置 |
| Delete | 将所选素材移到库回收站 |

## MCP 与专用 Skill

MCP 通过同一个本机库服务操作，不直接修改数据库。36 个工具覆盖库选择、查找、导入、标签、目录、关联、预览、材质、角色排序、备份、取用、问题和任务。先读取 `library_list` 的真实库 ID；修改资产前取得最新 revision；长操作返回 job_id 后需要查询最终状态。

`preview_resolve` 的 `source_only` 可忽略封面并读取原素材或备份，用于材质贴图。主题参数支持 `ivory`、`graphite`、`ocean`、`mint`，兼容旧 `light`/`dark`。启动配置示例见 [MCP 说明](../mcp/README.md)，工作流见 [imagidock-assets Skill](../.agents/skills/imagidock-assets/SKILL.md)。所有入口保存在项目或便携目录中，不自动安装全局配置或 Shell 扩展。
